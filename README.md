# One Letter for Your Day — Z

Entry for the make.fun bounty [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36). The program writes a single letter — **Z** — to `entry.txt` in the output directory: exactly one byte, UTF-8, no trailing newline, verified by a self-check after writing.

## Why Z

Z stands for **zero sleep**.

- **Vivid** — it paints one specific picture: a face at 4 a.m., lit by a screen, running on fumes. Not a vague mood, a scene.
- **Funny** — it lands instantly, because everyone has lived that day. It is the joke and the confession in a single character, the kind you retell to a friend.
- **True** — this entry was written in the small hours of a day with literally zero sleep behind it. An honest field report, not a performance.

A for "amazing" is the obvious pick. Z is the far end of the alphabet for the far end of the night.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

The output directory defaults to `/output` when `MAKEFUN_OUTPUT_DIR` is not set. The program writes `entry.txt` there and exits non-zero if its self-check fails.
